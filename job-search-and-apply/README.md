# Job Search and Apply

Use this skill to find openings that fit a provided resume and explicit job preferences, then return a shortlist of companies, roles, and application links for you to review and apply yourself. It saves the full shortlist to a CSV at a private, user-selected location. The skill does not submit applications or track submissions.

The skill checks relevant job boards and company career sites, including LinkedIn, Indeed, Naukri, Glassdoor, Cutshort, Wellfound, Foundit, Instahyre, Y Combinator Jobs, and Remote OK where accessible. It prioritizes core fit rather than requiring every preferred qualification, and reports which sources were checked and any search limitations. It does not handle credentials or bypass platform restrictions.

See [SKILL.md](SKILL.md) for the workflow and safeguards. On each run, provide the resume and explicit job preferences; provide a private CSV destination or choose one when asked.
