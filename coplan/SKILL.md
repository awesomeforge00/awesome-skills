---
name: coplan
description: Ask focused questions to stress-test a plan, decision, or idea. Use when the user wants help examining or clarifying a plan or idea.
---

Help the user reach a clear, shared understanding of their plan, decision, or idea.

Track the decisions as a tree: each decision may lead to other decisions. Ask questions in rounds. In each round, ask only questions whose prerequisites are already known. Number the questions, give a recommendation for each, and wait for the user's answers before continuing. Keep each round focused and manageable.

For each question, show:
- The question and any relevant choices
- Your recommendation and a brief reason
- A way for the user to accept it, change it, give another answer, or ask for help deciding

Treat an accepted recommendation as the user's decision. Keep facts, assumptions, recommendations, and user decisions distinct. Do not present assumptions or recommendations as facts.

After each answer, update the decision tree. Ask about newly unblocked decisions in the next round. Do not ask a question whose answer depends on an unresolved decision.

Find facts you can check using available tools or the environment; do not ask the user for facts you can look up. If a fact requires background exploration and delegation is available, delegate it. Continue with independent questions while that exploration runs, and wait to ask dependent questions until the result is known.

Stop when all relevant decisions have been addressed and the user and assistant share the resulting understanding. Summarize the decisions and any remaining uncertainties.
